How to Connect

  1. Get the client

    A clean Lineage II High Five Part 5 client (Windows; on macOS through CrossOver, Whisky or a virtual machine).

  2. Point it to the server

    Add this line to your hosts file (as Administrator):

    server-address l2authd.lineage2.com

  3. Log in

    Type any new username and password: your account is created on first login.
